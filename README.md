# 🐍 Python Labs · Анализ данных

Лабораторная по анализу успеваемости студентов с pandas и matplotlib.

| Материал | Назначение |
| --- | --- |
| [executed_lab.ipynb](executed_lab.ipynb) | Notebook с сохранённым выполнением |
| [lab_template.ipynb](lab_template.ipynb) | Исходный notebook |
| [report.html](report.html) | HTML-отчёт |
| [data/StudentsPerformance.csv](data/StudentsPerformance.csv) | Учебный датасет |

## Запуск

```sh
python -m venv .venv
python -m pip install -r requirements.txt
python -m pip install jupyter
python -m jupyter notebook
```

Выберите notebook. Для изолированного окружения запускайте команды установки через Python из `.venv`.
